### 概念纠正

- asyncio 等待时，事件循环在同一线程中推进其他就绪协程；asyncio.gather 不意味着调度另一个线程。await 本身不创建线程。调用同步阻塞函数会占用该事件循环线程。
- with 是否可用取决于本地 SDK 对象是否实现上下文管理协议，不是远程模型是否“支持 with”。
- 上游 SDK 处理供应商调用及结束原因，API 层将结果转换成客户端 NDJSON 事件。本服务响应头发出后不能更改自己的 HTTP 状态，不是所有层都无法处理或查看 HTTP 状态码。
- 调用生成器得到生成器对象；消费迭代器时才逐步执行其正文。流式输出与异步是两个独立维度，本次使用同步生成器同样能逐段响应。
