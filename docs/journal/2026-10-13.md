## 面试回答反馈

1. 两段 HTTP 通信解释基本正确；本实现为客户端→FastAPI、服务→模型 HTTP API。后端还负责输入校验、提示词构造、输出检查及错误映射。
2. CLI 退出状态与 HTTP 响应状态码的区别解释正确；进程退出会影响该 worker 正在处理的其他请求，不是用多线程与否判断是否需要退出码。
3. def 的选择应依据调用是否阻塞：当前 SDK 为同步调用；FastAPI 将普通 def 路由交给线程池运行。async def 中直接执行同步网络调用会占住事件循环，等待期间其他协程难以推进。异步接口也可以配异步 SDK，或明确把同步调用放到线程池。
4. 模拟测试能验证输入校验、分支、状态码、返回字段、调用参数及次数；不能证明真实供应商协议、网络、额度和模型效果正确。它不只是证明“能返回”。
